About Jolgue Harness

A personal AI agent workspace, built to connect your own model endpoints.

What it is

Jolgue Harness is a self-hosted web interface and agent API. It connects a Qwen chat model and a Z-Image-Turbo image service to one workspace.

Core features

Multi-turn chat, tool calling, web search, restricted terminal commands, workspace file access, image generation, and SQLite conversation records.

How it runs

The web app and API run on ShardCloud. Model inference can run separately on Kaggle or another reachable server. Cloudflare can provide a public HTTPS route to the app.

Configuration

Settings entered here are written to config.json by the server. API secrets are never returned to the browser; blank key fields keep the existing key unless you select Clear.

Privacy & data

Conversation history in this browser is stored in local storage. Server-side API events are stored in the configured SQLite database. Requests sent to model and image endpoints are processed by those services; review their privacy and retention policies.

Security

Use a strong application API key, keep model keys private, and expose the app only over HTTPS. The terminal has an allowlist and runs without a shell, but this is a personal project and should not be treated as a hardened multi-user security boundary.

Limitations

Model endpoints must already be running and reachable. Qwen must support OpenAI-compatible chat completions and tool calling. The image endpoint must return a supported image URL or base64 response. Tool execution and model output can be imperfect.
